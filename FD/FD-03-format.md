# FD-03-format · 格式兼容（OOXML / ODF / OFD）

## 说明
打通主流文档格式互通：OOXML（docx/xlsx/pptx）/ ODF / OFD（国产格式），以及 PDF⇄Office 的部分双向转换。

## 注释（细节 · 坑）
- OFD 为国产格式，需独立解析/导出路径，与 OOXML 不同。
- PDF⇄Office 为「部分」：受 PDF 版面还原限制（见 `FD-02-pdf`），非像素级。
- 复用优先：能用既有解析模块不裸造。

## 目标（对应 G / VG）
- **G**：格式互通（多格式读/写）。
- **VG**：全功能可交付。

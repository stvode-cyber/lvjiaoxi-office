# FD-04-cloud · 账户与云端

## 说明
统一账号体系 / 云端同步 / 备档 / `.lvjx` 加密存档格式。

## 注释（细节 · 坑）
- `.lvjx` 为项目自有存档格式（加密），是文档模型 OS.UOM 的持久化载体。
- 登录设定可选：默认游客直接进入，不强制登录；可在「账户与存储」开启「启动时要求登录」（纯逻辑 `OS.AuthPolicy.shouldGate`，见 `_auth_policy_test` 7 断言）。
- 云端同步依赖外部服务；沙箱仅验证逻辑，真实同步需联网账号。

## 目标（对应 G / VG）
- **G**：账户与云端（统一身份 + 备档）。
- **VG**：全功能可交付。

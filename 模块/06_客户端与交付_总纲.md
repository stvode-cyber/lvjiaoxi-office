# 模块 06 · 客户端与交付 总纲

> 模块级总纲：只负责「模块目的 / 包含子文件 / 当前状态 / 与其他模块关系」。
> 具体实现细节下沉到子文件（本轮仅规划，见 §二）。

## 一、模块目的

四端原生壳 + PWA，全部**同源承载** Web 真源 `app/`：
**Electron（桌面 Win/Mac/Linux）/ Android（Gradle WebView）/ iOS（Xcode WKWebView）/ HarmonyOS（DevEco ArkTS Web 组件）/ PWA（离线可安装）**。
同步纪律：`scripts/sync-clients.js` 严格镜像 `app/`，**零漂移**。

## 四、与其他模块关系

- **镜像 ← Web 真源（app/）**：所有客户端由 `sync-clients` 严格镜像，改 `app/` 后必同步。
- **下游 → 发版与更新（07）**：四端工程与 `scripts/` 是发版/更新的输入。
- **依赖 → 外壳与通用（05）/ 账户与云端（04）**：登录/账户全平台必备（PRD 强制）。
- **被 测试质量（08）** 间接覆盖（`npm run sync:check` 校验同源）。

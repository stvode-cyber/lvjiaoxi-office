# 模块 07 · 发版与更新 总纲

> 模块级总纲：只负责「模块目的 / 包含子文件 / 当前状态 / 与其他模块关系」。
> 具体实现细节下沉到子文件（本轮仅规划，见 §二）。

## 一、模块目的

四平台发布闭环：**版本单一真源 → 构建 → 自检 → 发版 → 静默更新 → 商店合规**。
工具位于 `scripts/`（Node 脚本）+ GitHub Actions CI；服务端零依赖 `server/`。

- **输入 ← 客户端与交付（06）**：四端工程与 `scripts/` 是发版输入。
- **联动 → 账户与云端（04）**：后台更新清单与账户模块联动。

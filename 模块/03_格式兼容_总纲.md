# 模块 03 · 格式兼容 总纲

> 模块级总纲：只负责「模块目的 / 包含子文件 / 当前状态 / 与其他模块关系」。
> 具体实现细节下沉到子文件（本轮仅规划，见 §二）。

## 一、模块目的

文档格式的**导入 / 导出 / 互操作**：OOXML（docx/xlsx/pptx）、ODF（odt/ods/odp）、OFD（国标版式）、PDF⇄Office 转换、多格式打开。
核心入口：`OS.Exporter`（原生生成规范 XML，JSZip 打包）、`OS.Importer`（解析再编辑）、`OS.COMPAT`（兼容等级 A 完全 / B 基本 / C 只读）。

| 子文件 | 内容 | 状态 |

| `ooxml-export.md` | DOCX/XLSX/PPTX 原生导出（含图片嵌入 `word/media/*`） | 规划中（待建） |
| `ooxml-import.md` | docx/xlsx/pptx 往返导入（`OS.COMPAT`、图片往返） | 规划中（待建） |

# 模块 01 · 文档编辑 总纲

> 模块级总纲：只负责「模块目的 / 包含子文件 / 当前状态 / 与其他模块关系」。
> 具体实现细节下沉到子文件（本轮仅规划，见 §二）。

## 一、模块目的

承载五大核心编辑能力：**Writer（文字）/ Spreadsheet（表格）/ Presentation（演示）/ MindMap（脑图）**。
Web 真源位于 `app/js/modules/{writer,spreadsheet,presentation,mindmap}.js`，零构建经典脚本 SPA，全局 `OS.*` 命名空间。

## 二、包含子文件

| 子文件 | 内容 | 状态 |
|--------|------|------|
| `writer.md` | Writer 流式排版、样式/大纲、批注评论、查找替换、页面设置；导出 DOCX/HTML/TXT/PDF | 规划中（待建） |
| `spreadsheet.md` | 公式引擎、冻结窗格、图表、条件格式、排序/筛选、数据验证；导出 XLSX/CSV/HTML/JSON | 规划中（待建） |
| `presentation.md` | 母版、过渡/动画、分页；导出 PPTX | 规划中（待建） |
| `mindmap.md` | 节点编辑 / 大纲式梳理；导出 JSON | 规划中（待建） |

## 四、与其他模块关系

- **下游 → 格式兼容（03）**：导出 DOCX/XLSX/PPTX/JSON 复用 `OS.Exporter`；导入往返由 `OS.Importer` 解析再编辑。
- **下游 → PDF（02）**：Writer/Presentation 可导出 PDF；PDF 的导出 DOCX 复用本模块文档模型。
- **上游 ← 外壳通用（05）**：ribbon 功能区、命令面板、撤销/重做在此挂载。
- **上游 ← 账户云端（04）**：文档经统一账号备档/同步。
- **被 测试质量（08）** 覆盖（公式、冻结、图表、导出等断言）。

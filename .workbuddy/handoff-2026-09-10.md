## 7. 关键工程纪律（不可破坏）

1. **Trust-but-Verify**：不靠「已创建 / 已修复」判定完成，必须回查产物（跑测试、grep 落盘、读文件）。
2. **严格忠实镜像**：iOS / HarmonyOS webroot 必须与 `app/` 一致；改完 `sync-clients` 后仍要检查 `clients/*/index.html` 是否带上了新 script 标签。
3. **版本单一真源**：只改 `package.json`，再 `bump-version.js`；**测试断言不得硬编码版本**（读 package.json）。
4. **版本号必须全落点一致**：package.json / version.json / 安装包属性 / 更新通道 must 相同（用户明确要求）。
5. **测试诚实**：失败先诊断根因，禁 sleep 重试循环。
6. **零依赖优先**：沙箱可测的纯逻辑抽独立模块（IIFE + OS 全局 + module.exports）；**测试专用依赖进 devDependencies，禁外部 workspace 路径**。
7. **图标不可臆造**：新增 ribbon 按钮前先 `grep app/js/icons.js`。
8. **文档回写**：每轮更新 STATUS / FEATURES / 对应模块总纲 + 当日日志 + 交接文档。
9. **PowerShell 环境**：git 与 node 均需手动拼 PATH；`&&` 不可用，用 `;`。

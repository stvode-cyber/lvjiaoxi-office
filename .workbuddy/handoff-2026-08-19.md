## 3. 工程现状（关键路径速查）

### 3.1 技术栈
- **前端**：零构建经典 `<script>` SPA + 全局 `OS.*` 命名空间。无打包器，无框架。
- **后端**：零依赖 Node `http` server（`server/index.js`），scrypt + HMAC，30 天 token。
- **桌面**：`electron/` + `electron-builder` generic publish provider。
- **移动端**：`clients/android/`（Gradle，自托管 API32→targetSdk 35）、`clients/ios/`（Capacitor 脚手架 + Xcode，WKWebView）、`clients/harmonyos/`（DevEco ArkTS Web 组件）。
- **运行时**：Node 20/22；测试 Node 二进制 `C:/Users/Administrator/.workbuddy/binaries/node/versions/22.22.2/node.exe`。

### 3.2 单一真源
- `package.json` 的 `version` = 全项目版本单一真源，由 `scripts/bump-version.js` 注入到所有工程。
- Web 端 = `app/`；iOS webroot / HarmonyOS rawfile = 仓库副本，由 `scripts/sync-clients.js` 同步。
- 桌面更新 = `feed-config.js` 解析 `LVJX_UPDATE_FEED` / GitHub Release 回退。

### 3.3 测试与门禁（关键命令）

```bash
# 全量门禁（必须 exit 0）
npm test
# 等价于：node scripts/run-tests.js && npm run sync:check

# 单独跑套件
node _pdf_convert_test.js

# 同步四端（修过 app/ 后必跑）
node scripts/sync-clients.js
node scripts/sync-clients.js --check   # 仅校验

# 跑云端集成测试
npm run cloud:test

# 启动云后端
npm run cloud
```

测试运行器特性：
- 自动发现根目录 `_*_test.js`，子进程隔离。
- 统一超时（单套件 60s 上限），失败隔离不污染其它套件。
- 并发=CPU 数 - 1（开发机偶发 `_auth_backup_test` 抖动属并行子进程资源争用，隔离重跑稳定）。

### 3.4 关键文件 / 模块契约
- `app/js/os.js` 全局命名空间。
- 模块：`OS.modules[type].mount(host, doc, ctx)` —— 文档打开 / 切换 / 离开由外壳统一调度。
- 文档模型 `OS.UOM`，存储于 `localStorage`（离线）或云端（`server/data/<user>.json`）。
- 自动备份：`.lvjx` 存档 + 每 5 分钟定时器 + 云端拉取同步。

## 8. 关键工程纪律（不可破坏）

1. **Trust-but-Verify**：不靠"已创建/已修复"状态描述判定完成；必须跑测试回查产物（命令退出码 / 测试输出 / 实际文件内容）。
2. **严格忠实镜像 / 零漂移**（KMP 工程纪律）：iOS / HarmonyOS webroot 必须与 `app/` 一致；改 `app/` 后必跑 `sync-clients`；`npm test` 已纳入此门禁。
3. **版本单一真源**：改版本只动 `package.json`，由脚本注入；禁止手工同步多端版本字段。
4. **测试必须诚实**：发现失败 → 诊断根因，禁止 sleep 重试循环；同一错误连续失败停下分析。
5. **回写文档**：每轮必更新 `FEATURES.md`；功能验证后必追加 `.workbuddy/memory/YYYY-MM-DD.md`。
6. **中文长篇结构化交付**：汇报含任务拆分、执行策略、最终交付摘要、表格、验证摘要、进展总览、显式 unittest 计数、代码块命令。
7. **零依赖优先**：沙箱内可单测的纯逻辑必须抽出独立模块，便于 node 直跑测试。
8. **不破坏 PRD 完整性**：PR 摘要 + 标注依据（套件数 + 断言数）作为完成判定。

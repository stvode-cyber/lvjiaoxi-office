## 7. 关键工程纪律（不可破坏）

1. **Trust-but-Verify**：不靠「已创建 / 已修复」判定完成，必须回查产物（跑测试、grep 落盘、读文件）。
2. **严格忠实镜像**：iOS / HarmonyOS webroot 必须与 `app/` 一致；改完 `sync-clients` 后仍要检查 `clients/*/index.html` 是否带上了新 script 标签（**已连续多轮需要补提**，AP/AQ/AR 都中招）。
3. **版本单一真源**：只改 `package.json`，再 `bump-version.js`。
4. **测试诚实**：失败先诊断根因，禁 sleep 重试循环。
5. **零依赖优先**：沙箱可测的纯逻辑抽独立模块（IIFE + OS 全局 + module.exports）。
6. **图标不可臆造**：新增 ribbon 按钮前先 `grep app/js/icons.js`。
7. **文档回写**：每轮更新 STATUS / FEATURES / 对应模块总纲 / FD 卡 / 当日日志。

## 8. 高频踩坑（PDF 字节级解析，跨特性复用）

> 完整版见 `.workbuddy/memory/MEMORY.md`，此处只列最容易再犯的。

- **合成测试 PDF 必须带 `trailer << /Root N 0 R >>`**：`findRootDict` 锚 `/Root` 正则，缺 trailer 则全表挂。
- **`sliceDict` 族闭合要含末位 `>`**：`slice(startIdx, i + 1)`，写成 `i` 会丢末位 `>`，嵌套字典（如 `/Names` 三层）必失衡。6 模块已修，勿退回旧写法。
- **ObjStm 合成偏移表必须 `num off` 严格交错**（`"2 0 3 38 4 84 "`）：错一位 `parseObjStm` 会把 offset 当对象号 → 幻影对象。
- **startxref 偏移用 `pdf.length` 实时计算**，手算必错位。
- **`/Prev` 链是增量更新回溯的权威依据**；`readTrailerAt` 双路径（`trailer` 关键字优先，找不到再按 `/Type /XRef` 取 xref 流对象字典）。
- **`OS.PdfTool.parsePdf` 页面树 walk 无环保护**：/Kids 环会栈溢出；做页面树遍历的模块须自带 visited 安全走树（AQ 已内置，勿改为依赖 `parsePdf.pages`）。
- **字面串分词**：`(` 起 depth=1，`)` 使 depth≤0 即停；操作符词按空白/特殊字符截断（`isNumCh` 含 e/E 会切出孤立 e → OOM）。
- **内容流解释用操作数栈**（操作符从栈顶弹），不能前向贪婪 `eatNum()`。
- **引用正则 `/(\d+)\s+\d+\s+R/` 捕的是对象号**，不是代数；`getObjDict` 须锚定 `num+"\s+0\s+obj\s*<<"`。
- **Edit 工具幻影写入**（会话级现象，已多次实测）：回执成功但磁盘未变 —— **每次 Edit 后必须 grep / Read 回查**；批量改动优先整文件 `Write` 原子重写。
- **构建通道坑**：用 PowerShell 后台包装起 electron-builder 会被回收成僵尸（进程亡、无产物）；改用 **Bash 后台通道**。构建命令：`NODE_OPTIONS="" npx electron-builder --win --publish never`（退 0，约 30s）。

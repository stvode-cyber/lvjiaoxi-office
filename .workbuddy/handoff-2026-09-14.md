## 1. 项目全景

### 1.1 这是什么

**绿角犀 Office** = Electron 桌面应用，**一个跨平台办公套件**。对标 WPS Office，但走精简 + AI 增强路线。

```
核心能力：文字 Writer | 表格 Spreadsheet | PDF | 演示 Presentation | 脑图 Mindmap
差异化：内置 AI 块级编辑（润色/改写/扩写/解释）、BYOK 云端、版本历史快照
UI：单页 SPA 风格 — 侧边栏切模块、功能区 ribbon、画布中心
```

### 1.2 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 框架 | **Electron 31.7.7** | nodeIntegration=true + contextIsolation=开 |
| 渲染层 | **原生 JS**（无框架） | IIFE 模块 + OS 命名空间统一挂载 |
| 存储 | **IndexedDB**（Store 自封装） | VER=3，store: docs + backups + versions |
| PDF | **pdf.js 原生渲染 + pdf-lib 内容流重写** | pdf.js v4.x 渲染 + pdf-lib 做 editTextOnPage |
| 思维导图 | **纯 SVG 渲染**（无 d3 依赖） | layoutMap() 自动水平树布局 |
| 表格 | **Canvas + 自实现公式引擎** | 支持 SUM/AVG/IF/RANK 等 |
| 演示 | **DOM slides + SVG** | 每页一个 div，支持 AI 生成 |
| 打包 | **electron-builder** | NSIS 安装包 + portable |
| AI 本地 | **规则引擎**（summarize/polish/rewrite/expand/outline...） | 零依赖 |
| AI 云端 | **fetch 直接调**（BYOK） | OpenAI/Claude/DeepSeek/Gemini 预设 |
| 解压 | **JSZip**（node_modules 里可用） | XMind + 未来 PPTX |

## 5. 关键架构坑（接手要避开）

| 坑 | 教训 | 解法 |
|----|------|------|
| **审计脚本误报严重** | "事件泄漏 352" → 真泄漏只有 1 处；"IPC 孤儿" → 实际已配对 | 审计脚本必须分层：DOM 级 vs window/doc 级 |
| **PowerShell 5 正则引号乱码** | `"['\"]"` 在 PS 双引号里被解释器吃了 | 写 Node 脚本文件执行，不要 inline -e |
| **全文件 regex replace 会毁东西** | escapeHtml 删函数定义 / hex 替换破坏 CSS style 字符串 | edit 用精确 old_string；replace 必须限定语义位置 |
| **Electron preload vs nodeIntegration** | renderer 层直接 `require("zlib")` / `require("jszip")` 能用是因为 nodeIntegration=true | 别随便改 main.js 里的 webPreferences |
| **Mindmap 默认颜色不能用 CSS 变量** | SVG rect 的 fill 属性用 `getAttribute("fill")` 读不到 CSS 变量 | 保留硬编码颜色常量 |
| **CDP Runtime.evaluate 返回值取法** | `data.result.result.value` 是真正的 JS 值，不能直接 `JSON.parse(msg)` | 拆两层 result |
| **npm start 会开 CDP :9222** | 可以直接用 Node + ws 连 CDP 做黑盒测试，不需要 browser_use | 写 Node 脚本调用 CDP WebSocket |

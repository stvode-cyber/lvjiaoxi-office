## 修复 1：多标签页不同格式文件互相覆盖

### 根因
`markdown.js` 的 `mount()` 函数直接 `host.innerHTML = ""`，把 `#module-host` 里之前所有标签页的模块容器全部清掉了。其他 5 个模块（pdf/writer/mindmap/presentation/spreadsheet）都正确地创建独立 `div.module-wrap` 再 append 到 host，唯独 markdown 绕过了。

### 修复
- **markdown.js**：创建 `div.module-wrap.markdown-wrap`，所有 DOM 操作挂 wrap 上，结尾 `host.appendChild(wrap)`；return 的 `el` 改为 `wrap`；删掉 `host.innerHTML = ""` 和 `host.style.cssText = ...`
- **spreadsheet.js**：wrap className 从 `"sheet-wrap"` 补为 `"module-wrap sheet-wrap"`（zoom 选择器兼容性 + 规范化）
- **shell.js**：清理上一轮诊断加的 console.time/log 调试语句

### 审计结果
`grep host.innerHTML = "" modules/` 扫全模块 → 零处残留。所有 6 个模块 wrap className 均含 `module-wrap`。

## 修复 2：PPT 左侧缩略图只有空框

### 根因
渲染管线顺序陷阱：CSS `.pres-canvas` 设了 `position:absolute`，renderSlide 对缩略图用 `transform: scale(140/760)` 缩小。但浏览器先按 DOM 尺寸做 overflow clip（pres-thumb 的 overflow:hidden），再应用 transform。结果 760×427 的 canvas 先被 pres-thumb（140×78）裁到只剩左上角一小块，再 scale(0.184) → 约 26×14px，肉眼不可见。

### 修复
renderSlide 的缩略图分支（scale !== 1）直接设 `width = W*scale`、`height = H*scale`、`position = static`，不再用 transform 缩放。主画布（scale = 1）不受影响，仍走 CSS absolute + 视口自适应缩放。

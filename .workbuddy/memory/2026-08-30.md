## AC · PDF 附件（EmbeddedFiles）提取与下载

承接「按顺序。你全权往下开发」指令，收口发布全绿后继续字母序下一特性 AC。

### 1. 纯模块 `app/js/modules/pdf-attachments.js`（零依赖）
- `parseRawAttachments(bytes, opts)`：扫描 `/Names /EmbeddedFiles` 名称树
  - 两种形态：平铺 `/Names [(name) filespec ...]` + 递归 `/Kids [node ...]`（已支持嵌套）
  - `extractDictAfter` / `extractArrayAfter` 支持 `<<>>` / `[]` 嵌套匹配
  - Filespec → `/EF` → `/F|/UF|/D` 定位内嵌文件流对象号
  - `locateStream` 在二进制字节中按对象号定位 `stream…endstream`，剥 EOL，`/Filter /FlateDecode` 走 `inflateRawSync`（Node zlib 兜底，浏览器回退 `getAttachments`）
  - `decodeName` 还原 `#2F` 与 UTF-16BE 中文文件名
- 返回 `[{name, mime, size, data, compressed, desc}]`；附 `toMarkdown` 导出清单。
- IIFE + `OS.PdfAttachments` + `module.exports` 三件套（缺一则 Node require 失败）。

### 2. UI 接线
- `app/index.html` 纯模块区接入 `pdf-attachments.js`（pdf-outline 之后）。

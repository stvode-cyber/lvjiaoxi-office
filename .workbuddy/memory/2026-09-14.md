## 遇到的坑

| 坑 | 教训 | 解法 |
|----|------|------|
| CDP Runtime.evaluate 返回值取法 | Runtime.evaluate 返回 `{result:{result:{value:...}}}` 三层 | 拆两层 result |
| 审计脚本误报严重 | "事件泄漏 352" 实际上只有 1 处真泄漏 | 审计脚本必须分层（DOM 级 wrap.remove 自动清 vs window/doc 级） |
| browser_use 连不上 | 用户环境 Chrome 没开 + 没装 TRAE 扩展 | 换 CDP 直接连 Electron :9222 |
| PowerShell inline -e 正则炸 | `"['\"]"` 在 PS 双引号里被解释器吃了 | 写 Node 脚本文件执行 |
| mkNode 默认颜色 undefined | SVG fill 属性不能用 CSS 变量（纯属性赋值，不走 computedStyle） | 硬编码 `#2563eb` |
